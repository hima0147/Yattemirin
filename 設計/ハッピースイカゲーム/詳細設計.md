# 『ハッピースイカゲーム』詳細設計書

## 1. プロジェクト基本設定
* **Unity Version**: 2021.3 LTS 以上推奨 (2Dコア)
* **ターゲット解像度**: `1344 * 2257` (Portrait)
* **Pixels Per Unit (PPU)**: `100` を基準とする。
* **画面比率・余白対応**: `Canvas Scaler (Expand)` と背景用 `Image` を用いて、どのような解像度の端末でも中央に1344x2257のプレイエリアを確保し、はみ出た部分をメインカメラの背景色（水色：`#7ECEF4`）の余白として表示する。

## 4. 主要コンポーネント・Inspector設定詳細

### 4.1 Environment (プレイエリアの壁と床)
* **位置計算**: PPU=100とした場合のWorld座標系での設定。基準サイズ `1344 * 2257` を World座標 `13.44 * 22.57` として扱う。
* **Wall_Left / Wall_Right**:
  * `BoxCollider2D`: 画面端から `113px (1.13 units)` 内側に配置。
  * `Rigidbody2D`: アタッチしない（静的コライダー）。
* **Floor**:
  * `BoxCollider2D`: 画面下から `140px (1.40 units)` 上に配置。
* **GameOverLine**:
  * `BoxCollider2D`: 画面上から `710px (7.10 units)` 下に配置。`Is Trigger` を `True` に設定。

### 4.2 Canvas_Background (背景・余白用キャンバス)
* **Canvas**:
  * `Render Mode`: Screen Space - Camera (Main Cameraを指定)
* **Canvas Scaler**:
  * `UI Scale Mode`: Scale With Screen Size
  * `Reference Resolution`: X=1344, Y=2257
  * `Screen Match Mode`: **Expand** (これで余白を実現)
* **GameBackground (Image)**:
  * `Rect Transform`: Width=1344, Height=2257
  * `Color`: プレイエリアの背景色

### 4.3 UI キャンバス設定
* **Canvas Scaler**:
  * `UI Scale Mode`: Scale With Screen Size
  * `Reference Resolution`: X=1344, Y=2257
  * `Screen Match Mode`: Match Width Or Height (Match=0.5 または アスペクト比に応じて動的制御)

### 4.4 SuikaUIManager & SuikaGameManager の連携
* **SuikaGameManager.cs**:
  * `GameObject[] fruitPrefabs`: インスペクターから11種類のPrefabをセット。
  * 状態管理列挙型 `GameState { Title, Ready, Playing, GameOver }` を持つ。
* **SuikaUIManager.cs**:
  * タイトル画面、ゲーム画面UI、各ポップアップの `GameObject` の参照を持ち、`SetActive()` で表示/非表示を切り替える。
  * 「あそびかた」は配列 `Sprite[] howToPages` と `Image pageDisplay` を持ち、現在のページインデックス(`int`)で画像を切り替え、下部のページインジケーターの色を更新する。

## 5. ゲームルール・スコア仕様
* **ネクスト抽選**: レベル0(ポテト) ～ レベル4(ひまわり) のインデックスから `Random.Range(0, 5)` で抽選。
* **落下位置の制限**: キャラクターのX座標の可動域は、画面端から `207px` 内側を上限下限とする(`Mathf.Clamp`を使用)。
* **合体（進化）ロジック**:
  1. `SuikaFruit.cs` の `OnCollisionEnter2D` にて、衝突相手のTagが `Fruit` かつ `level` が自身と同じか判定。
  2. 双方の `isMerging` フラグを立てて2重発火を防止。
  3. `SuikaGameManager` に合体イベントを通知（中間座標の算出、スコア加算、次のレベルのPrefabのInstantiateを依頼）。
  4. 自身と衝突相手を `Destroy`。
  5. スイカ(level=10)同士の合体の場合は、消滅エフェクトを再生しInstantiateは行わない。
* **スコア表** (衝突時に加算):
  * Lvl 1(イチゴ生成): +1 / Lvl 2(サクラ): +3 / Lvl 3(リンゴ): +6 / Lvl 4(ひまわり): +10 / Lvl 5(いよかん): +15 / Lvl 6(みかん): +21 / Lvl 7(もも): +28 / Lvl 8(ぶどう): +36 / Lvl 9(パイナップル): +45 / Lvl 10(スイカ): +55 / スイカ消滅: +100
* **称号評価基準**:
  * 1000点未満: ブロンズ / 1000点以上: シルバー / 1500点以上: ゴールド / 2000点以上: プラチナ
