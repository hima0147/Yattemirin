# 『ハッピースイカゲーム』詳細設計書

## 1. プロジェクト基本設定
* **Unity Version**: 2021.3 LTS 以上推奨 (2Dコア)
* **ターゲット解像度**: `1344 * 2257` (Portrait)
* **Pixels Per Unit (PPU)**: `100` を基準とする。
* **画面比率・余白対応**: `Canvas Scaler (Expand)` と背景用 `Image` を用いて、どのような解像度の端末でも中央に1344x2257のプレイエリアを確保し、はみ出た部分をメインカメラの背景色（水色：`#7ECEF4`）の余白として表示する。

## 4. 主要コンポーネント・Inspector設定詳細

### 4.1 Environment (プレイエリアの壁と床)
* **位置計算**: PPU=100とした場合のWorld座標系での設定。基準サイズ `1344 * 2257` を World座標 `13.44 * 22.57` として扱う。
* **Wall_Left / Wall_Right**:
  * `BoxCollider2D`: 画面端から `113px (1.13 units)` 内側に配置。
  * `Rigidbody2D`: アタッチしない（静的コライダー）。
* **Floor**:
  * `BoxCollider2D`: 画面下から `140px (1.40 units)` 上に配置。
* **GameOverLine**:
  * `BoxCollider2D`: 画面上から `710px (7.10 units)` 下に配置。`Is Trigger` を `True` に設定。

### 4.2 Canvas_Background (背景・余白用キャンバス)
* **Canvas**:
  * `Render Mode`: Screen Space - Camera (Main Cameraを指定)
* **Canvas Scaler**:
  * `UI Scale Mode`: Scale With Screen Size
  * `Reference Resolution`: X=1344, Y=2257
  * `Screen Match Mode`: **Expand** (これで余白を実現)
* **GameBackground (Image)**:
  * `Rect Transform`: Width=1344, Height=2257
  * `Color`: プレイエリアの背景色

### 4.3 UI キャンバス設定
* **Canvas Scaler**:
  * `UI Scale Mode`: Scale With Screen Size
  * `Reference Resolution`: X=1344, Y=2257
  * `Screen Match Mode`: Match Width Or Height (Match=0.5 または アスペクト比に応じて動的制御)

### 4.4 SuikaUIManager & SuikaGameManager の連携
* **SuikaGameManager.cs**:
  * `GameObject[] fruitPrefabs`: インスペクターから11種類のPrefabをセット。
  * 状態管理フラグ（`_isGamePlaying`, `_isPaused`, `isDebugMode` 等）を持ち、ゲームの進行を管理。
  * 時間停止（`Time.timeScale = 0f`）を利用したポーズ機能とリトライ処理を行う。
* **SuikaUIManager.cs**:
  * タイトル画面、ゲーム画面UI、各ポップアップ（ゲームオーバー、ポーズ、リトライ確認、「あそびかた」）の `GameObject` の参照を持ち、`SetActive()` で表示/非表示を切り替える。
  * プレイ画面の背景に描かれたアイコンの上に透明なボタンを配置し、各ポップアップを呼び出す。
  * 「あそびかた」は配列 `Sprite[] howToPages` と `Image pageDisplay` を持ち、現在のページインデックス(`int`)で画像を切り替え、下部のページインジケーターの色を更新する（後日実装）。

### 4.5 デバッグ機能・その他制御（追加）
* **隠しデバッグ起動**: タイトル画面左上の透明ボタン（Btn_DebugStart）から起動すると `isDebugMode = true` となる。
* **デバッグ操作**:
  * ゲーム中のスコアテキストをタップで「強制ゲームオーバー」。
  * ネクストアイコンをタップで「待機中の果物を全11種類の中で順次切り替え」。
* **UI貫通防止**: `SuikaPlayerController` にて `EventSystem.current.IsPointerOverGameObject()` を用い、UI操作中（ボタン押下中など）は果物の移動・落下処理をキャンセルする。

## 5. ゲームルール・スコア仕様
* **ネクスト抽選**: レベル0(ポテト) ～ レベル4(ひまわり) のインデックスから `Random.Range(0, 5)` で抽選。デバッグモード中はタップで全種類から任意選択可能。
* **落下位置の制限**: キャラクターのX座標の可動域は、画面端から `207px` 内側を上限下限とする(`Mathf.Clamp`を使用)。
* **合体（進化）ロジック**:
  1. `SuikaFruit.cs` の `OnCollisionEnter2D` にて、衝突相手のコンポーネントを取得し `fruitLevel` が自身と同じか判定。
  2. 双方の `_hasMerged` フラグを立てて2重発火を防止。
  3. **通常進化 (レベル10未満)**: `SuikaGameManager` に合体イベントを通知し、中間座標に一段階上の果物を生成。自身と衝突相手を `Destroy`。
  4. **ダブルスイカ (レベル10同士)**: 進化は行わず、双方を `Destroy` してボーナススコアを加算（箱のスペースを空ける大逆転ギミック）。
* **スコア表** (衝突時に加算):
  * 基本スコア: 進化後のレベル × 10点 (例: Lvl 1生成で+10点、Lvl 2生成で+20点...等)
  * ダブルスイカ消滅ボーナス: +1000点
* **称号評価基準** (ゲームオーバー時に判定):
  * 500点未満: ブロンズ / 500点以上: シルバー / 1500点以上: ゴールド / 3000点以上: レジェンド
